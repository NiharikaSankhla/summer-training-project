# Titanic Survival Prediction Project

## Project Overview
This project is an End-to-End Machine Learning application developed using Python, Docker, Jenkins, and GitHub. The model predicts whether a passenger survived the Titanic disaster based on input features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Docker
- Jenkins
- GitHub

## Project Components
- Machine Learning Training Script
- Prediction Application
- Monitoring Script
- Docker Containerization
- Jenkins CI/CD Pipeline
- Docker Hub Publishing

## Files Description

- train_model.py : Model training script
- app.py : Prediction application
- monitor.py : Monitoring script
- model.pkl : Saved trained model
- titanic.csv : Dataset file
- Dockerfile : Docker configuration
- Jenkinsfile : CI/CD pipeline script
- requirements.txt : Python dependencies
